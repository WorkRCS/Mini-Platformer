# Characters

Put these exact files here:
- \`player.glb\`
- \`enemy_grunt.glb\`
- \`boss_chapter_01.glb\`

Use realistic game-ready rigged humanoids. Each file must include the skeleton, embedded textures, and its animation clips. The model origin should be at the feet, Y up, forward +Z, and height approximately 1.7–2.0 units.

Player clips: \`Idle\`, \`Walk\`, \`Run\`, \`Jump\`, \`Attack\`, \`Hit\`, \`Death\`.
Enemy/boss clips: \`Idle\`, \`Walk\` or \`Run\`, \`Attack\`, \`Hit\`, \`Death\`.

Do not rename FBX files to GLB. Convert/export the actual model and clips into GLB first.
