# Runtime assets

This folder is packaged into the Android APK. Use lowercase folder and filename spelling exactly; Android asset paths are case-sensitive.

Required drop-in files:
- \`characters/player.glb\`
- \`characters/enemy_grunt.glb\`
- \`characters/boss_chapter_01.glb\`
- \`environment/chapter_01.glb\`

Optional:
- \`audio/chapter_01.ogg\`

Character animation clips must be embedded in the same GLB as the rigged character. See each subfolder README and the root README before downloading assets.
